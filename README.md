# 📊 Data Visualization

A collection of data visualization projects and practical examples demonstrating how to **explore, analyze, and communicate data effectively** using different visualization tools and techniques.

This repository contains various **charts, plots, dashboards, and interactive visualizations** created using Python as well as other popular data visualization and Business Intelligence tools.

---

##  Tools & Technologies

- **Python** — Matplotlib, Seaborn, Plotly
- **Power BI** — Interactive dashboards, DAX, Power Query
- **Excel** — Charts, Pivot Charts, and Dashboards
- **Tableau** — Interactive dashboards and visual analytics
- **Jupyter Notebook** — Data analysis and visualization
